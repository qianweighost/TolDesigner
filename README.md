# 尺寸链公差分析计算器 · TolDesigner

一款 Windows 桌面计算工具，做尺寸链（公差累积）的两件事：

- **正算 / 公差分析** —— 已知各组成环公差，求封闭环的公差带、合格率与制程能力；
- **反算 / 公差分配** —— 已知封闭环要求，把公差分配到各组成环，并给出推荐的 IT 等级。

算法口径对齐 **华为研发内部《公差分析》方法**：极值法与统计法并重，
用 Cp / Ppk、σ 水平、PPM 评价批量生产的合格率。

界面与同门的 *O 形密封圈设计计算器（OringDesigner）*、*齿轮同步带传动设计计算器（DriveDesigner）*
共用一套视觉与交互规范，合称「**设计计算器家族**」。

数值口径由外部硬锚点锁死（华为内部胶片算例 + GB/T 1800 标准表值），
见 `tools/selftest.py`，**209 项断言全部通过**（含示意图几何自检与界面冒烟）。

## 二、功能与页签

| 页签 | 主要内容 |
|---|---|
| **尺寸链计算** | 组成环表格（编号 / 名称 / 基本尺寸 / 上下偏差 / 环型 / 分布状态 / ξ 下拉）、**标准选取弹窗**（常用配合 / 加工方式 IT / 标准件 / 螺栓通孔 / PCB / 连接器）、封闭环要求、极值法与统计法双结果、Ppk 与合格率、尺寸链简图、公差带图、各环贡献率排序、报告导出 |
| **公差仿真** | 蒙特卡洛抽样（上限 200 万次，可固定随机种子复现），给出实际分布直方图、LSL/USL、合格率与各环方差占比 |
| **公差分配** | 按「等公差 / 等公差等级 / 按权重」三种方法反算各环公差，给出推荐 IT 等级与分配依据，一键把结果应用到尺寸链页复算 |
| **标准公差库** | GB/T 1800.1 的 IT01~IT18 全表、σ 水平 / PPM 对照表、内置基本偏差代号速查（按代号取上下偏差） |
| **使用说明** | 方法口径、全部公式、三步上手、常见坑与免责声明（F1 直达） |

三个计算页共享同一份尺寸链数据，切页时自动同步。

## 三、计算口径

### 符号

| 符号 | 含义 |
|---|---|
| `Aᵢ` / `N₀` | 组成环 / 封闭环基本尺寸 |
| `ξᵢ` | 传递系数：增环 +1，减环 −1；非平行环（斜面/投影）可在界面显式指定 ±0.866 / ±0.707 / ±0.577 / ±0.5 |
| `Tᵢ` | 公差带**全宽**（`T = ES − EI`；界面上的 ± 值是**半带**，`T = 2×±`） |
| `Δᵢ` | 中间偏差 `(ES + EI)/2` |
| `kᵢ` / `eᵢ` | 相对分布系数 / 相对不对称系数，`σᵢ = kᵢ·Tᵢ/6` |
| `σ₀` | 封闭环标准差 |

### 正算

| 项目 | 公式 |
|---|---|
| 封闭环基本尺寸 | `N₀ = Σ ξᵢ·Aᵢ`（ξ 可为任意显式系数，非平行环常用 cos30°=0.866 等） |
| 极值法 WC | `T₀ = Σ Tᵢ`，`ES₀ = Σ ξᵢΔᵢ + T₀/2`，`EI₀ = Σ ξᵢΔᵢ − T₀/2` |
| 统计法 RSS / 概率法 | `σ₀ = √(Σ ξᵢ²σᵢ²)`，`T₀ = 6σ₀` |
| 中间偏差 | `Δ₀ = Σ ξᵢ·(Δᵢ + eᵢ·Tᵢ/2)` |
| 制程能力 | `Cp = (USL−LSL)/(6σ₀)`，`Ppk = min(USL−μ₀, μ₀−LSL)/(3σ₀)`，`σ 水平 = 3·Ppk + 1.5` |
| 热膨胀修正 | 勾选后每环按 `Aᵢ×(1+αᵢ·ΔT)` 修正，`ΔT = 工作温度 − 20 ℃` |

### 反算（公差分配）

| 方法 | 规则 |
|---|---|
| 等公差 | 极值法 `Tᵢ = T₀/n`；统计法 `Tᵢ = T₀/√n` |
| 等公差等级 | 按 `Tᵢ = a·i(Dᵢ)` 反解公差因子系数 `a`，就近归入标准 IT 等级 |
| 按权重 | 按各环权重的平方根（统计法）或权重（极值法）比例分摊 |

> **等公差等级法会与目标值有差额** —— 因为它必须归入标准 IT 等级，
> 不可能刚好等于算出来的理想值。界面上会明确标出差额百分比。

### 为什么「≥4 个累积尺寸」要改用统计法

极值法假设**所有环同时取到各自的极限**，这在批量生产中概率极低。
华为内部胶片给了一个很有说服力的例子：

| 项 | 值 |
|---|---|
| 5 个 ±0.05 的环，极值法 WC | ±0.25 |
| 5 个 ±0.05 的环，统计法 RSS | ±0.11 |
| 出现「全部取到极限」的概率 | 约 0.001 PPM |
| 若要求累积 ±0.25，统计法下每环可放宽到 | ±0.1 |

所以内部口径是：**≤3 个累积尺寸用极值法，≥4 个用统计法**。
本工具会按组成环个数自动给出建议口径（结果卡上的「← 建议口径」）。

但要注意：**极值法并非没用**。安全件、单件小批、装配后不可返修的场合，
仍应当用极值法保证 100% 互换。

### 「σ 水平 + 1.5」是怎么回事

长期生产中制程中心会缓慢漂移，业界惯例留 **1.5σ** 漂移量，
所以「6σ 水平」对应的不良率才是众所周知的 **3.4 PPM**，
而不是正态分布理论上的 0.002 PPM。本工具的 σ 水平与华为胶片的 PPM 对照表完全一致：

| σ 水平 | 1σ | 2σ | 3σ | 4σ | 5σ | 6σ |
|---|---|---|---|---|---|---|
| PPM | 691462.5 | 308537.5 | 66807.2 | 6209.7 | 232.6 | 3.4 |

## 四、标准依据

| 标准 | 用途 |
|---|---|
| GB/T 1800.1-2020 | 极限与配合：公差、偏差和配合的基础（IT 等级、公差因子 `i = 0.45·∛D + 0.001·D`） |
| GB/T 1800.2-2020 | 标准公差带代号和孔、轴的极限偏差表 |
| GB/T 5847-2004 | 尺寸链 计算方法 |
| GB/T 5371 | 极限与配合 过盈配合的计算和选用 |
| ISO 286-1 / ISO 286-2 | 公差带与基本偏差国际系列 |
| 机械设计手册（第六版）第 1 卷 | 公差与配合、尺寸链 |
| GB/T 5277-1985 | 螺栓和螺钉通孔：精装配 H12 / 中等装配 H13 / 粗装配 H14（M3~M20 通孔直径入表） |
| GB/T 275（常用口径） | 滚动轴承配合：内圈旋转负荷轴 k6、外圈固定座孔 H7、游动端座孔 JS7 |
| GB/T 1095 | 平键联结：正常联结毂槽 JS9、松联结槽宽 H9 / 毂槽 D10 |
| GB/T 119.1 | 圆柱销：销径 h8；销孔铰制后 H7 |
| IPC 体系（IPC-2221 等） | PCB 常规制程能力值：PTH ±0.08/±0.15、NPTH ±0.05、压接孔 ±0.05（各厂有差异，参考值） |

「标准选取」弹窗里的**加工方式 → IT** 一栏取的是机械设计手册/互换性教材通行的
**经济加工精度**口径（如精车 IT7~9、钻孔 IT11~13、精磨 IT6~7），填入值取区间中位
等级按 ±IT/2 对称换算；**连接器**一栏的接触件等级（精密 IT5~6 / 普通 IT7~8）
为行业常用口径。这两处都不是强制标准条款，选型时请结合自家工艺能力确认。

### 内置的基本偏差代号

- **轴（小写）**：`d e f g h js k`
- **孔（大写）**：`D E F G H JS K`

**未内置**：`a b c`（大间隙）、`j m n p r s t u v x y z za zb zc`
—— 这些代号在国标里含分段修正量 Δ，本工具不提供以免给出近似值，
请在组成环表里直接填写上/下偏差。

内置代号的公式值取整到 1 μm，与标准表值可能存在 ±1~2 μm 的差异
（例如 φ50e8 得 −0.049/−0.088，手册表值为 −0.050/−0.089）。

## 五、几个容易踩的坑

| 坑 | 说明 |
|---|---|
| 目标值不要填 0 | 目标值留空 = 按算出的 N₀ 取偏差带（最常用）；填 0 会按绝对尺寸比对而判超差 |
| `T` 与 `±` 不是一回事 | `T` 是全宽，`±` 是半带，`T = 2×±`；华为胶片写的「±0.25」是本工具的 `T = 0.5` |
| 等公差等级法的差额 | 归入标准 IT 等级后累积值必然与目标有差，属正常，界面会标出差额 |
| 自动判增减环 | 需要先填封闭环目标值（基本尺寸），否则无从反解；反解会清空全部显式 ξ |
| 显式 ξ 与环型联动 | 切增环/减环会把 ξ 清回自动 ±1；显式 ξ 时环型跟随其符号 |
| 标准选取弹窗 | 配合/IT/通孔按选中环基本尺寸换算；PCB 与连接器为行业常规值，各厂有差异 |
| 分布状态 | 只影响统计法与蒙特卡洛，极值法不受影响 |
| 热膨胀 | 勾选后按 20 ℃ 基准修正，各环 α 需自行填对 |

## 六、本工具没有做的部分

- **形位公差环**：可以用「基本尺寸填 0、上偏差填公差值、下偏差填 0、分布选均匀」
  的方式手工加进尺寸链，但没有做专门的形位公差建模块。
- **多闭环联合优化**：一次只算一条封闭环，多条链请分别建、分别算。
- **基本偏差全谱**：只内置上表那 14 个代号，其余请直接填上下偏差。
- **三维尺寸链**：只做线性链（传递系数 ±1）。角度链需自行折算成线性环后输入。

## 七、开发与构建

### 环境

需要 Python 3.9+ 与 PySide6-Essentials：

```bat
pip install -r requirements.txt
python app.py
```

### 自检

```bat
python tools\selftest.py            :: 全量（数值 + 示意图几何 + 界面冒烟 + 截图）
python tools\selftest.py --no-ui    :: 只跑数值校验，不出界面
```

自检产物落在 `tools/out/`：`selftest.txt` 为报告，`shot_*.png` 为五个页签的截图。

> 截图**不要**设 `QT_QPA_PLATFORM=offscreen`：该平台没有字体数据库，
> 中文会渲染成豆腐块，容易误判排版。正确做法是默认平台 +
> `WA_DontShowOnScreen` 属性，拿到真实字体渲染的画面。

### 打包为单文件 exe

```bat
build.bat
python tools\smoke_exe.py
```

脚本会先用 `tools/make_icon.py` 生成 `app.ico`（与运行时窗口图标同一套画法，
任务栏 / 标题栏 / exe 文件图标天然统一），再调 PyInstaller 打成单文件。
产物在 `dist\尺寸链公差分析计算器.exe`。

> **不要 exclude `PySide6.QtSvg`** —— 页眉的 GitHub / 地球图标由它渲染，
> 排除后图标会退化成占位方块。
